# Translations

`templates/owrtpc.pot` is generated by the official LuCI
`build/i18n-scan.pl` tool. Refresh it from this package directory:

```sh
/path/to/luci/build/i18n-scan.pl . > po/templates/owrtpc.pot
```

No translated `.po` catalogs are maintained by hand. Future translations belong
in `po/<language>/owrtpc.po`, managed through OpenWrt Weblate when the project is
accepted there. No feed submission or Weblate project has been created.
